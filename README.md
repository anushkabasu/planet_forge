# Planet Forge

A browser-based planet creation simulator. Customize a planet's size, color, atmosphere, rings, and moons, watch it update live in a rotating preview, and get an auto-generated scientific readout and collectible card for every world you create. Save you favorites to a personal archive that is saved on the device locally.

## Features

- Planet Customization (size, color, atmosphere, rings, and moon count with life controls)
- Live 3D-Style Preview (a rotating, gradient shaded planet that updates instantly)
- Collectible Planet Card (a card combining all generated info, plus a weighted rarity and a short description)
- Random Planet Generator (a button to instantly get a brand new random planet)
- Planet Archive (Save Planets to a personal collection stores on your device)

## Tech Stack

- HTML5
- CSS5
- JavaScript
- Google Fonts (Inter, Grotesk)
- Browser's 'localStorage' (for Planet Archive)

## Future Plans/ Improvements

- Additional Customization options for terrain, surface texture, cloud cover, etc.
- More detailed planet stats
- Export of Planet Cards as Images
